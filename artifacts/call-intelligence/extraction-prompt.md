# Extract evidence and commitments

Classification: simplified demonstration. The example contains no client transcript.

For each candidate statement, return: statement, source reference, category, approval state and any contradiction.

Categories: business fact, pain, objection, proposal, approved commitment, execution decision.

Use approved commitment only when the source explicitly authorizes the offer or claim. Keep tentative ideas as proposals. Separate a prospect-facing offer from an internal execution decision. Preserve conflicts instead of silently merging them. Return missing evidence as unknown.

Offer approval is a downstream authority boundary. Extraction quality must be checked against the actual source before production use.
